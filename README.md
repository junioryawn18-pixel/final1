Campus Life Super App
📌 Project Title
 Yaw Campus Life Super App

📖 Overview
The Campus Life Super App is a multi-page web platform built to connect students with essential university details, including upcoming activities, food options, and everyday resources. The site features a clean, intuitive interface divided into three core sections: Home, Events, and Dining.

🎯 Objective
This project serves as a Minimum Viable Product (MVP) to highlight practical web development skills. It illustrates how HTML, CSS, JavaScript, and API integrations work together to create a dynamic, mobile-friendly user experience.

💻 Tech Stack
HTML5 (for page structure)
CSS3 (for custom visual styling)
Bootstrap (for responsive layouts)
JavaScript (for dynamic behavior and DOM updates)
Fetch API (for handling data requests)
Git & GitHub (for source code management)
GitHub Pages (for live hosting)
